# 提前还款方案对比工作台

贷款服务人员使用的提前还款试算工作台：对**同一笔提前还款**，分别生成
**缩短期限（月供不变）** 与 **降低月供（期限不变）** 两种还款计划，
逐期展示本金、利息、剩余余额与**利率来源**，并对比两种方案在期数、月供、总利息上的差异。

- 后端：Spring Boot 3 + Java 21，全部金额使用 `BigDecimal`（2 位小数，HALF_UP）
- 数据库：PostgreSQL 16（保存模拟合同、利率时间表版本与每次计算记录快照）
- 前端：Angular 18（独立组件，利率时间轴编辑 + 逐期利率来源展示）
- **仅使用模拟合同，不连接任何真实放贷接口**

## 目录结构

```
backend/    Spring Boot 计算与持久化服务（端口 8080）
frontend/   Angular 工作台（开发端口 4200，/api 代理到 8080）
scripts/    本地环境（JDK / Maven / PostgreSQL）与启动脚本
```

## 分段利率时间表

每份合同维护一张**按生效日排列的分段利率时间表**：

- 利率段 `(生效日, 年利率)` 自生效日（含）起生效，至下一段生效日（不含）止，段间天然连续；
- 每次整体替换时间表都会**校验并保存为新版本**（版本号按合同递增），历史版本只读；
- 校验规则：**同一生效日只允许一段**（拒绝同日多次调整）、**首段生效日不得晚于计划起始日**
  （拒绝空档）、年利率 0 ~ 36% 且**最多 6 位小数**（精度校验）；
- 每次计算记录**计算时采用的版本号与完整时间表快照**，历史结果不随后续编辑漂移；
  可在历史记录上一键**派生新计算**（按合同当前版本重算，其余参数沿用原记录）。

## 计算规则（日期 + 分段计息）

- 第 i 期计息区间为 `[起始日+(i-1)个月, 起始日+i个月)`（月末日期向目标月最后一天钳位）；
- **期未跨调息日**：利息 = 期初余额 × 年利率 / 12（月利率保留 12 位小数）；
- **期跨调息日**：按实际占用天数分段 —
  `利息 = 期初余额 × Σ(年利率ᵢ × 天数ᵢ) / (12 × 当期天数)`，
  整期汇总后一次性四舍五入到分，无跨段/跨期累计误差；
- **等额本息**：月供 `M = P·r·(1+r)^n / ((1+r)^n − 1)`；利率调整后自**首个完整期**起
  按新利率对剩余本金、剩余期数**重算月供**，跨调息日的当期仍按原月供还款、仅利息分段；
- **等额本金**：每月偿还本金 `P / n` 固定，月供逐月递减；
- **缩短期限**：保持原月供水平（等额本息保持月供金额、等额本金保持月还本金），逐月模拟至结清；
- **降低月供**：期限不变，按提前还款后本金重新计算计划；
- **事件顺序**：提前还款在计划起始日计息前冲减本金；调息日与提前还款日重合时，
  顺序为 **新利率段生效 → 冲减本金 → 按新利率计第一期利息**；
- 提前还款金额直接冲减本金；手续费为一次性成本，计入总成本但不冲减本金；
- **末期自动结清**：末期本金 = 当期期初剩余本金，尾期后余额恰好为 0，不出现负余额。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/contracts` | 模拟合同列表 |
| POST | `/api/contracts` | 新建模拟合同（可附初始利率时间表，缺省为单一利率段 v1） |
| GET | `/api/contracts/{id}/rate-schedule` | 合同当前利率时间表（最新版本） |
| GET | `/api/contracts/{id}/rate-schedule/versions` | 利率时间表全部版本（新到旧） |
| PUT | `/api/contracts/{id}/rate-schedule` | 整体替换利率时间表（校验后保存为新版本） |
| POST | `/api/calculations/compare` | 生成两种方案对比并保存记录（含利率快照） |
| POST | `/api/calculations/{id}/derive` | 由历史记录派生新计算（默认采用合同当前利率版本） |
| GET | `/api/calculations` | 历史计算记录 |
| GET | `/api/calculations/{id}` | 单条计算记录（含完整结果与利率快照） |

利率在 API 与数据库中均为小数形式（`0.049` 表示 4.9%），前端负责 % 换算；
日期为 `yyyy-MM-dd`。手工录入试算时可直接传 `rateSchedule`（分段利率时间表），
缺省时以 `annualRate` 构成自 `scheduleStartDate` 起的单一利率段。

## 示例核对（与单元测试一致）

两种还款方式共用参数：剩余本金 1,000,000.00 元，年利率 4.9%（单一利率段），剩余 240 期，
提前还款 200,000.00 元，手续费 500.00 元（提前还款后本金 800,000.00 元）。

### 等额本息（月供固定）

| 指标 | 不提前还款（基准） | 缩短期限 | 降低月供 |
|---|---|---|---|
| 月供 | 6,544.44 | 6,544.44（不变） | 5,235.55 |
| 期数 | 240 | 170 | 240 |
| 总利息 | 570,665.67 | 310,467.06 | 456,532.99 |

逐期抽查（基准计划）：第 1 期利息 4,083.33、本金 2,461.11、余额 997,538.89；
末期（第 240 期）还款 6,544.51，结清后余额 0.00。缩短期限方案末期（第 170 期）
还款 4,456.70，结清后余额 0.00。

### 等额本金（月还本金固定）

| 指标 | 不提前还款（基准） | 缩短期限 | 降低月供 |
|---|---|---|---|
| 月还本金 | 4,166.67 | 4,166.67（不变） | 3,333.33 |
| 首月/末月月供 | 8,250.00 / 4,182.88 | 7,433.34 / 4,183.04 | 6,600.00 / 3,347.74 |
| 期数 | 240 | 192 | 240 |
| 总利息 | 492,041.29 | 315,233.07 | 393,633.72 |

逐期抽查（基准计划）：第 1 期本金 4,166.67、利息 4,083.33、月供 8,250.00；
末期本金兜底 4,165.87（= 1,000,000 − 239 × 4,166.67），结清后余额 0.00。

### 期中调息分段计息示例

剩余本金 120,000.00 元，等额本金，2026-01-01 起 12 期；利率 6% 自 2026-01-01 生效，
3% 自 2026-02-15 生效：

- 第 1 期（整期 6%）：利息 = 120,000 × 0.06 / 12 = **600.00**；
- 第 2 期 `[02-01, 03-01)` 跨调息日：14 天按 6%、14 天按 3%，
  利息 = 110,000 × (0.06×14 + 0.03×14) / (12×28) = **412.50**；
- 第 3 期起整期 3%：利息 = 100,000 × 0.03 / 12 = **250.00**。

结论（两种还款方式一致）：**缩短期限总利息明显更低，但月供压力不变；
降低月供保持期限、减轻月供压力，但总利息更高。** 本例中缩短期限比降低月供
节省利息：等额本息 146,065.93 元，等额本金 78,400.65 元。

> 上表数值由 `AmortizationServiceTest` / `SegmentedRateScheduleTest` 实际计算输出，
> 测试同时断言：各期本金合计 = 贷款本金、末期后余额为 0、全程无负余额、
> 每期月供 = 本金 + 利息、跨调息日的期按实际天数拆分且汇总准确、
> 同日多次调整 / 起始空档 / 超精度利率被拒绝、历史记录快照不随后续编辑漂移。

## 本地运行

```bash
# 1. 启动 PostgreSQL（用户态 PostgreSQL 16，无需 root；首次自动初始化并建库）
scripts/start-postgres.sh

# 2. 启动后端（端口 8080；已打 jar 则直接运行 jar，否则 mvn spring-boot:run）
scripts/start-backend.sh

# 3. 启动前端开发服务器（另开终端，端口 4200，/api 代理到 8080）
scripts/start-frontend.sh
# 打开 http://localhost:4200
```

前端生产构建后（`cd frontend && npx ng build`）将 `dist/frontend/browser`
复制到 `backend/src/main/resources/static`，即可由后端单端口 8080 同时托管页面与 API。

运行测试：

```bash
cd backend && ../tools/maven/bin/mvn test

# 端到端冒烟验证（需后端已启动）：分段计息、校验拒绝、版本化与派生
scripts/smoke-test.sh
```

> 本环境未预装 Java / PostgreSQL，`tools/` 下为免 root 的
> Temurin JDK 21、Maven 3.9 与 PostgreSQL 16（aarch64）运行时。
